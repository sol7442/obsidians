배경
기존의 전자서명은 개인키를 SW(메모리)로 로딩하여 사용함으로 .. 등의 문제가 있다.
 공동인증서, 금융인증서, 간편인증서 모두 
기술
TEE : CPU 내부의 안전한 실행공간에서 키를 사용하며, 키는 대부분 암호화되어 외부 저장장치에 저장된다.
SE/TPM/Secure Enclave : **칩 내부의 비휘발성 메모리에 키를 직접 저장**하는 구조이다.
FIDO 는 Attestation을 통해 어떤 보안 하드웨어(TEE, TPM, Secure Element 등)를 사용하는지, 해당 인증기가 인증받은 보안 수준을 충족하는지
FIDO 인증(Authenicator Certification)을 획득한 Authenticator는 개인키(Private Key)가 인증기 외부로 추출되지 않는(Non-Extractable) 보안 속성을 구현하도록 요구하며, 해당 구현이 인증 프로그램을 통해 검증된다.

FIDO Metadata에서도 확인 가능
keyProtection
KEY_PROTECTION_TEE
KEY_PROTECTION_SECURE_ELEMENT
KEY_PROTECTION_HARDWARE
개인키가 해당 Authenticator 외부에서 사용될 수 없는 구조인지 : isKeyRestricted ()
FIDO의 핵심은
개인키를 숨기는 것"이 아니라
개인키를 외부에서 사용할 수 없도록 설계하는 것
